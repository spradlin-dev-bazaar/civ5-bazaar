# Lua events for Bazaar mods

Generated by `tools/build_vmc_reference.py` in Bazaar's repository, from VMC v97's `CustomModOptions.xml` and Bazaar's engine source. Do not edit by hand; run the script again instead.

Each event is one of these kinds:

- **hook**: the game tells every handler; what they return is ignored.
- **test-all**: the game asks a yes-or-no question and treats the answer as yes only if every handler returns `true`.
- **test-any**: the game treats the answer as yes if any handler returns `true`.
- **value**: handlers return a number the game uses.

Subscribe with `GameEvents.<Name>.Add(function(<arguments>) ... end)`.

## VMC events: switched off until a mod switches on their option

Switch an option on in the mod's SQL: `UPDATE CustomModOptions SET Value = 1 WHERE Name = '<OPTION>';`

## VMC's other options

These change rules or add Lua functions rather than events. Switch them on the same way. An option marked **number** holds a number instead: set it with `UPDATE CustomModOptions SET Value = <number> WHERE Name = '<OPTION>';`.

- `GLOBAL_EARLY_COOP_WAR_LOCK`: If A declares war on B that preempts a co-op war, A is locked into the war for the same number of turns as if they had agreed to the co-op war (v86) See also: "Global - Early Coop War Lock"
- `GLOBAL_STACKING_RULES`: Changes the stacking limits based on what the tile is (city, fort, plain, etc) (v19) See also: "Global - 2 Units Per Fort" See also: "Global - 3 Units Per City"
- `GLOBAL_BREAK_CIVILIAN_1UPT`: This is the "No More Civilian Traffic Jams (NMCTJs) Mod" by Pazyryk - see http://forums.civfanatics.com/showthread.php?t=519754 (v45) See also: "Global - No More Civilian Traffic Jams"
- `GLOBAL_BREAK_CIVILIAN_RESTRICTIONS`
- `GLOBAL_LOCAL_GENERALS`: Great Generals and Admirals gained from combat experience spawn in the war-zone and not in a distant city (v19) See also: "Global - Local Generals"
- `GLOBAL_SEPARATE_GREAT_ADMIRAL`: Separates out the repair fleet and change port abilities of the Great Admiral (v61) If you enable this option, you will need to add back the abilities to the standard GA
- `GLOBAL_PROMOTION_CLASSES`: Permits units to have promotion trees different from their assigned CombatClass (v19) See also: "Promotions - Subs Silent Running" See also: "Promotions - AntiAir Specialisations"
- `GLOBAL_PASSABLE_FORTS`: Ships may enter coastal forts/citadels (v19) GLOBAL_PASSABLE_FORTS=0 ships may only enter player cities or pass through allied CS cities GLOBAL_PASSABLE_FORTS=1 ships may additionally enter coastal forts in player, allied CS or no-mans land GLOBAL_PASSABLE_FORTS_ANY=1 ships may additionally enter inland forts in player, allied CS or no-mans land See also: "Global - Passable Forts"
- `GLOBAL_PASSABLE_FORTS_ANY`: Ships may enter ANY forts/citadels (requires GLOBAL_PASSABLE_FORTS=1) See also: "Global - Passable Forts"
- `GLOBAL_ANYTIME_GOODY_GOLD`: Goody Huts can always give gold, stops the late-game issue where entering a goody hut can result in nothing being awarded (v22) See also: "Goody Huts - No Auto-Mapping"
- `GLOBAL_CITY_FOREST_BONUS`: Give initial production boost for cities founded on forests, as if the forest had been chopped down by a worker (v19) See also: "Global - City Forest Bonus"
- `GLOBAL_CITY_FOREST_BONUS_PERCENT` (**number**, default 125): Percentage of "ring-1 chop" (v47)
- `GLOBAL_CITY_JUNGLE_BONUS`: Give initial production boost for cities founded on jungle, as if the jungle had been chopped down by a worker (v72) See also: "Global - City Jungle Bonus"
- `GLOBAL_CITY_JUNGLE_BONUS_PERCENT` (**number**, default 125): Percentage of "ring-1 chop"
- `GLOBAL_CITY_WORKING`: Permit cities to work tiles up to MAXIMUM_ACQUIRE_PLOT_DISTANCE - WARNING! Cities take 2.5 times as much memory/file space (v19) See also: "Global - City Working Distance"
- `GLOBAL_CITY_AUTOMATON_WORKERS`: Permit cities to work additional slots (tiles and specialists) with automatons (v89) See also: "Tech - City Automaton Workers"
- `GLOBAL_RELOCATION`: Enables rebasing to and airlifting to/from improvements (v74) See also: "Units - Dwarf Broad Axeman"
- `GLOBAL_ALPINE_PASSES`: Mountain plots return their terrain as TERRAIN_MOUNTAIN and any land unit may enter a mountain that has a road/rail route (v19) See also: "Improvement - Tunnel"
- `GLOBAL_CS_GIFT_SHIPS`: City States will (occasionally) gift ships (v19) See also: "Global - City States Gifts"
- `GLOBAL_CS_UPGRADES`: Units in allied militaristic City States can upgrade - requires a (cosmetic) patch to UnitPanel.lua to fix the incorrect message about being in friendly territory (v19) See also: "in Global - CS Unit Upgrades"
