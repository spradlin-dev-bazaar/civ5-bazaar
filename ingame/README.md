The pop-up Bazaar shows in a game after a plugin crashes. It names the plugin, and closing it in any way returns the player to the main menu, since the game may be damaged; section 4 of docs/plugin-host.md explains why. The Bazaar mod adds it as an in-game screen, and the DLL shows it through the `BazaarPluginStopped` Lua event, or falls back to the game's text pop-up when this screen did not load. Its frame is adapted from the game's text pop-up, which is Firaxis code; see NOTICE.
