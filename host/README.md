The host's own code, compiled into the host DLL. Every `.cpp` file here is built into it, and the runtime tests build all of them but `CivHostEngine.cpp`.

- `CivPluginApi.h`: the contract with plugin DLLs. The Plugins screen's `bazaar:` calls and its `BazaarPlugins` table are Bazaar's own, not part of it, so they may change in any release, except what mod authors' copies of the in-game checker read: the table's Position, File, Status and Problems columns, and the status words.
- `CivHostRuntime`: the list of plugins and each plugin's life: adding a plugin to the list, refusing a plugin before it runs when the plugin is listed twice, could not be shut down safely earlier (its shutdown function crashed, or one of its threads was still running), or is built for another version of Bazaar, loading the plugins in order, keeping a plugin or turning it away after its entry function has run, unloading plugins, and the rows that the Plugins screen shows. Its header also gives the host's other files a plugin's record, whether a plugin is still on, and Bazaar's log.
- `CivHostCalls`: every call into a plugin's code, and what happens when the plugin crashes in one of them: the crash guard that turns a crashed plugin off instead of letting the game crash, and the calls to a plugin's hooks, entry function, shutdown function, save and load functions, Lua functions, and the functions that it publishes for other plugins.
- `CivHostHooks`: the lists of each function's hooks, and running the hooks: adding a plugin's hooks to the lists, running the before-hooks, the replacement, and the after-hooks, and removing every hook when the plugins unload.
- `CivHostRegister`: the table of functions that Bazaar hands each plugin when the plugin loads. A plugin calls some of these functions at any time, for example to write to Bazaar's log, to push a Lua function, to read and set values, and to call another plugin's published function. A plugin writes its save data only while its save function runs. Bazaar refuses a write at any other time and logs only the first such write. A plugin calls the others only while its entry function runs, to register hooks, hand-placed hooks, its save and load functions, values, and published functions. Bazaar holds those registrations until the plugin is kept or turned away, then puts them in effect or drops them.
- `CivHostConflicts`: conflicts between plugins: a plugin that replaces a function that a plugin higher in the list already replaces, a replacement that might skip a hand-placed hook or the carrying over of another plugin's values, and the pairs of plugins that the player chose to use together anyway.
- `CivHostImage`: a plugin's DLL file, without running any of the plugin's code: reading what the file exports, such as the version of Bazaar that the plugin was built for, and checking that none of the plugin's threads is still running inside the DLL before Bazaar frees the DLL.
- `CivHostSaves`: Bazaar's part of a saved game: each plugin's data under its mod's ID and plugin ID, and the data of plugins that are off, kept for the next save, and a mark when a plugin crashed before the game was saved.
- `CivHostValues`: the values plugins keep on players, cities, units and plots: reading and setting them, carrying them over to a new unit or city, and their place in Bazaar's part of a save.
- `CivHostFunctions`: the functions plugins publish for each other: which plugin published each one, under what name and type, and finding them.
- `CivHostCrash`: what Bazaar.log says about a plugin's crash: where it happened, what memory it touched, and its call stack, with function names from the plugin's `.pdb` when it has one.
- `CivHostHand`: the hand-placed hooks: the engine's calls from inside its functions, and how each one reaches the plugins.
- `CivHostOrder`: the plugin order the player sets on the Plugins screen: the text it is saved as, matching it to the listed plugins, and the screen's rows and notes.
- `CivHostNotices`: the notices waiting for a game to show them, and naming a lasting problem only once a game.
- `CivHostMods`: the mods the game has switched on, as its own mod database lists them: finding a plugin's DLL or a screen's file among their files, and refusing a plugin whose mod does not affect saved games.
- `CivHostModSwitch`: the fix for the game's bug in switching mods when a save loads or a replay is viewed. Bazaar finds the game's four faulty loops by their machine code, runs the checks before it changes the four loops, and puts the fix into the game's code.
- `CivHostSetup`: finding the Advanced Setup screen that the Plugins screen replaced, so Continue can open it, and checking that no other mod's Advanced Setup comes before the Plugins screen.
- `CivHostDlc`: the UI skins of the DLC packs in the game's folder, whose files the game shows in place of its own, and which pack's file the game takes for a screen.
- `CivHostPath`: file names and paths. Bazaar keeps them in UTF-8 and gives them to Windows as wide characters, so names in any language work.
- `CivHostEngine`: the link to the game: the plugin list and the switched-on mods from its databases, the saved order file, the Plugins screen's calls, the log file, Bazaar's part of the game's saves, telling which player, city, unit or plot a value is on, Lua's `Game.GetPluginValue`, and showing notices in the game.
- `CivHostHooks.h`: what the generated hook wrappers need from the runtime.
- `CivHostHookList.h`: the hook lists' functions that the host's other files use: a hook's name, adding a plugin's hook to the lists, removing every hook, which plugin's replacement of a hook point is in effect, and which plugins registered for a hand-placed hook, in load order.
- `CivHostPart.h`: writing and reading the numbers and texts Bazaar's part of a save is made of.
- `CivHostLock.h`: a small lock class that the rest of Bazaar's host uses where two threads share data that only one thread at a time may use, since Civilization V writes one save from a thread of its own, and runs hooked functions on two threads at the same time, its drawing thread and its game core thread.
- `CivTurnBench.h`: a turn timer used only in benchmark builds.
