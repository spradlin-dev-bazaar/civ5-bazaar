The build-time generator that writes a hook wrapper for every engine function, `CivHooks.h` with the types of each hook point's hooks for plugins, the host's export list, and the list of functions that contain each hand-placed hook.

`layouts.py` is the layout check: it compares every class the SDK's headers define, with its fields' types and its virtual functions' parameters, and every enum value of the game's headers and `CivPluginApi.h`, against the record in `class-layouts.txt`. Class templates are checked only through the sizes of their uses. `layout_types.py` reads the types and values with the libclang that `requirements.txt` pins. To change a layout on purpose before 0.5, run `build-hooked.cmd accept-layouts`, then rebuild every plugin; from 0.5 on, the check's message says how. The release the freeze starts at is `FREEZE` in `common.py`, which the release script reads too.

The build marks each engine function and global variable for export one at a time, in its generated copy of the engine, rather than marking whole classes: marking a class makes the compiler build member functions the game never uses, and some of those don't compile. A DLL can export at most 65,535 names; Bazaar 0.5.0 exports about 15,200, listed in `tools/released/exports.txt`.
