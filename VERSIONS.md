# Bazaar's mod versions

The game's Mods menu shows Bazaar's mod version, such as "v 5". Releases after 0.5.1 also name their release in Bazaar's description in that menu. Each version of Bazaar is a separate mod whose mod versions start again at 1, so this file has a table for each version of Bazaar, under a heading such as "## Bazaar 0.5", with the newest version's table first. Each table gives the release for every mod version of that version's mod, newest first. The table for Bazaar 0.5 also lists the releases before 0.5, from 0.3.0 to 0.4.1, because they used the same mod. A release that changes only the SDK or the docs can keep the last release's Bazaar and its mod version. It then has no row of its own.
